# Project rules for Claude

## No attribution footers

Do not add any AI attribution or "generated by" lines anywhere:

- Commit messages: no `Co-Authored-By: Claude ...` and no `Claude-Session: ...` trailers.
- Pull request descriptions: no `Generated with Claude Code` line and no session links.
- GitHub comments, reviews and issue comments: no `Generated by [Claude Code](...)` footer.

Commits are authored by the repository owner. Follow the commit message convention in `CONTRIBUTING.md`.
